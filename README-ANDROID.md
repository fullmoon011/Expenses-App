# چۆنیەتی کارپێکردن لە ناو Android Studio (How to Run in Android Studio)

ئەم پڕۆژەیە بە سەرکەوتوویی لەگەڵ **Android Studio** بە بەکارهێنانی **Capacitor** ڕێکخراوە و فۆڵدەری ڕەسەنی `android/` دروستکراوە.

---

### هەنگاوەکان بۆ کردنەوە و کارپێکردن لە Android Studio:

1. **دابەزاندنی کۆدەکە (Download / Clone)**:
   - کۆدی پڕۆژەکە دابگرە لەسەر کۆمپیوتەرەکەت.

2. **کردنەوەی پڕۆژەکە لە Android Studio**:
   - بەرنامەی **Android Studio** بکەرەوە.
   - کلیک بکە لەسەر **Open**.
   - فۆڵدەری **`android`** (کە لە ناو ڕەگی پڕۆژەکەدایە) هەڵبژێرە و **OK** دابگرە.
   *(تێبینی: گرنگە ڕاستەوخۆ فۆڵدەری `android` بکەیتەوە نەک فۆڵدەری سەرەکی پڕۆژەکە).*

3. **سەرکەوتنی Gradle Sync**:
   - Android Studio بە شێوەیەکی ئۆتۆماتیکی فایلەکانی Gradle دادەبەزێنێت و پڕۆژەکە Sync دەکات.
   - ئەگەر پەیامی نوێکردنەوەی Android SDK دەرکەوت، پەسەندی بکە.

4. **کارپێکردن لەسەر مۆبایل یان ئیمولەیتەر (Run App)**:
   - ئیمولەیتەرێک (Virtual Device - AVD) هەڵبژێرە، یان مۆبایلی ئەندرۆیدەکەت لە رێگەی وایەری USB یان Wi-Fi ببەستەرەوە (لەگەڵ چالاککردنی USB Debugging).
   - کلیک لە دوگمەی سەوزی **Run (▶)** لە بەشی سەرەوەی Android Studio بکە.
   - ئەپڵیکەیشنی **داهاتوو** لەسەر مۆبایلەکەت دەکرێتەوە!

---

### دروستکردنی فایلی APK ڕاستەوخۆ:
لە ناو Android Studio:
1. لە مینیۆی سەرەوە بڕۆ بۆ **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
2. پاش کەمێک فایلی `app-debug.apk` ئامادە دەبێت لە ناو:
   `android/app/build/outputs/apk/debug/app-debug.apk`
3. دەتوانیت ڕاستەوخۆ ئەم فایلە بنێریت بۆ مۆبایلەکەت و دایبەزێنیت (Install).

---

### فەرمانە خێراکان لە تێرمیناڵەوە:
- بۆ نوێکردنەوەی گۆڕانکارییەکانی دیزاین و کۆد لەگەڵ ئەندرۆید:
  ```bash
  npm run cap:build
  ```
- بۆ کردنەوەی ڕاستەوخۆی پڕۆژەکە لە Android Studio بە فەرمان:
  ```bash
  npm run cap:open
  ```
